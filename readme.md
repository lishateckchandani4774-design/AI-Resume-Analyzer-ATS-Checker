# 📄 AI Resume Analyzer & ATS Checker
An intelligent **AI-powered Resume Analyzer** built with **Python** and **Streamlit** that evaluates resumes against Applicant Tracking System (ATS) standards. The application extracts resume content from PDF files, analyzes technical skills, calculates an ATS score, recommends career paths, identifies missing skills, matches resumes with job descriptions, and provides actionable suggestions to improve employability.

---

## 🚀 Features

### 📄 Resume Upload
* Upload resumes in PDF format.
* Automatically extracts text from the uploaded resume.

### 📊 ATS Score Calculation
* Calculates an ATS score based on detected technical skills.
* Displays:
  * ATS Score
  * Skills Found
  * Missing Skills
* Interactive progress indicator.

### 🏅 Resume Strength Assessment
Classifies resumes into different levels:
* 🚀 Industry Ready
* ⭐ Advanced
* 📘 Intermediate
* 🌱 Beginner

### ✅ Skill Detection
Automatically identifies technical skills such as:
* Python
* SQL
* Machine Learning
* Deep Learning
* NLP
* AWS
* Docker
* Java
* Power BI
* Excel
* Linux

### ❌ Skill Gap Analysis
Highlights missing skills that can improve ATS compatibility.

### 💡 Resume Improvement Suggestions
Provides recommendations to enhance the resume, including:
* Adding technical skills
* Including certifications
* Mentioning projects
* Improving ATS compatibility

### 🎯 Career Recommendations
Suggests career paths based on detected skills, including:
* Data Scientist
* Machine Learning Engineer
* AI Engineer
* Data Analyst
* Cloud Engineer
* Software Developer

### 💻 Project Recommendations
Recommends projects to strengthen the candidate's portfolio.

### 🏆 Certification Recommendations
Suggests industry-recognized certifications based on the user's skill set.

### 📈 Interactive Dashboard
Visualizes resume analysis using:
* Bar Chart
* Pie Chart
* ATS Progress Indicator

### 📋 Candidate Summary
Generates an HR-friendly summary including:
* ATS Score
* Resume Level
* Employability Status
* Recommended Career

### 🎯 Resume vs Job Description Matcher
Compare a resume with a job description using Natural Language Processing.

Features include:
* Resume Match Score
* Keyword Matching
* Missing Keywords
* ATS Improvement Suggestions
